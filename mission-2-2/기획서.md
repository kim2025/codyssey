# 나무가 자라는 할일 플래너

## 대상 사용자

- 나 혼자 쓰는 개인용 페이지입니다. 주로 PC에서 사용합니다.

## 사용 목적

- 매일 할일을 확인하고, 추가하고, 삭제하고, 체크합니다.
- 오늘 할 일을 빠뜨리지 않고, 매일 꾸준히 하는 습관을 만듭니다.
- 할일을 끝낼 때마다 나무가 자라는 모습을 보며 동기부여를 받습니다.

## 화면 구성과 동작

- 첫 화면은 한눈에 볼 수 있는 대시보드입니다. 달력, 선택한 날의 할일 목록, 진행률, 나무가 한 화면에 함께 보입니다.
- 달력
  - 한 달 단위로 보이고, 이전 달/다음 달 버튼으로 이동합니다.
  - 오늘 날짜는 따로 표시됩니다.
  - 처음 열면 오늘 날짜가 선택되어 있습니다.
  - 날짜를 누르면 그 날짜가 선택되고, 목록·진행률·나무가 그 날 기준으로 바뀝니다.
  - 할일이 있는 날에는 점이 표시됩니다.
  - 할일을 모두 끝낸 날에는 체크 표시가 나타납니다.
- 선택한 날의 할일 목록
  - 입력칸에 글을 쓰고 엔터를 누르거나 추가 버튼을 누르면 할일이 추가됩니다. 빈 글은 추가되지 않습니다.
  - 항목 옆의 체크 칸을 누르면 완료/미완료가 바뀝니다.
  - 항목 옆의 ✕ 버튼을 누르면 "정말 지울까요?" 확인창이 뜨고, 확인하면 삭제됩니다.
  - 지난 날, 오늘, 미래 날짜 모두 추가하고 체크할 수 있습니다.
- 진행률
  - 선택한 날의 완료 개수와 전체 개수(예: 3/5)와 퍼센트 막대가 보입니다.
- 나무
  - 선택한 날의 완료 비율에 따라 5단계로 자랍니다. 비율은 완료 개수 ÷ 전체 개수입니다.
  - 체크하거나 체크를 풀 때마다 나무가 부드럽게 커지거나 작아집니다.
  - 그날 할일을 전부 끝내면 꽃잎이나 반짝이가 흩날리는 축하 효과가 나옵니다.
  - 할일이 하나도 없는 날은 씨앗 상태로 보이고 "할일을 추가해 보세요" 안내 문구가 나옵니다.
- 화면 분위기는 밝고 따뜻한 느낌(연두, 크림색 위주)입니다.
- 넓은 화면에서는 달력과 목록·나무가 나란히 놓이고, 좁은 화면에서는 위아래로 쌓입니다.

## 필요한 자료

- 사용자가 입력하는 할일: 내용, 날짜, 완료 여부
- 나무 5단계 그림: 외부 이미지 파일 없이 코드로 직접 그립니다.
- 안내 문구와 버튼 이름 등 화면에 쓰이는 글

## 완료 기준

- 페이지를 열면 오늘 날짜가 선택된 상태로 달력, 목록, 진행률, 나무가 모두 보입니다.
- 입력칸에 글을 쓰고 엔터 또는 추가 버튼을 누르면 선택한 날의 목록에 할일이 추가되고, 달력의 그 날짜에 점이 생깁니다.
- 체크 칸을 누르면 완료 표시가 되고, 진행률 숫자·막대와 나무가 바로 바뀝니다. 다시 누르면 원래대로 돌아옵니다.
- ✕ 버튼을 누르면 확인창이 뜨고, 확인하면 삭제되며 취소하면 그대로 남습니다.
- 달력에서 다른 날짜를 누르면 그 날의 할일, 진행률, 나무가 보입니다.
- 한 날의 할일을 모두 완료하면 나무가 마지막 단계가 되고 축하 효과가 나오며, 달력의 그 날짜에 체크 표시가 생깁니다.
- 나무 단계(초안): 0%는 씨앗, 1~33%는 새싹, 34~66%는 어린 나무, 67~99%는 큰 나무, 100%는 꽃이나 열매가 달린 나무입니다.
- 할일이 없는 날은 씨앗과 안내 문구가 보입니다.
- 새로고침하거나 브라우저를 껐다 켜도 같은 브라우저에서는 할일과 체크 상태가 그대로 남아 있습니다.
- 브라우저 창 폭을 좁혀도 가로 스크롤 없이 내용이 위아래로 정리되어 보입니다.
- 꼭 지켜야 할 조건: 다른 파일, 로그인, API 키, 서버 없이 HTML 파일 하나로 열립니다.

## 추가 기능

- 매일/요일별 반복 할일
- 다른 기기로 옮기기(내보내기/불러오기 또는 서버를 이용한 동기화)
- 삭제 실행 취소
- 이번 주/이번 달 요약, 연속으로 다 완료한 날 수
- 다크 모드

## 한계 및 비목표

1. 로그인, API 키, 서버가 필요한 기능은 이번 구현에서 제외합니다.
2. 데이터는 이 브라우저에만 저장됩니다. 다른 브라우저나 다른 기기(폰 등)와 자동으로 공유되지 않습니다.
3. 브라우저의 사이트 데이터를 지우면 할일도 함께 사라집니다.
4. 반복 할일, 알림, 삭제 실행 취소, 주간·월간 요약, 연속 달성 기록은 이번 범위에서 제외합니다.
5. 나무는 선택한 날의 완료 비율만 반영하며, 날짜를 넘어 누적되지 않습니다.

## 검증 방법

- 할일을 몇 개 추가하고 일부만 체크한 뒤, 진행률 숫자와 퍼센트를 손으로 계산한 값(완료 ÷ 전체)과 비교합니다.
- 완료 비율이 0%, 1~33%, 34~66%, 67~99%, 100%가 되도록 만들어 보고, 나무 단계가 위 기준과 맞는지 확인합니다.
- 할일을 추가·체크·삭제한 뒤 새로고침해서 상태가 그대로인지 확인합니다.
- 서로 다른 날짜에 할일을 넣고 날짜를 바꿔 가며 목록·진행률·나무·달력 표시가 날짜별로 맞게 나오는지 확인합니다.
- 브라우저 창 폭을 점점 줄여 보며 화면이 겹치거나 잘리지 않는지 확인합니다.
