### 선택한 결과물과 근거:

AI B - Claude Sonnet 5.5 가 만든 html 결과물로 선택함. 같은 행동을 해도 사용성 면에서 더 편리하고 시인성이 더 좋다고 판단.

- AI A - GPT-6 가 만든 결과물에서 달력에 선택한 날짜의 모든 할일을 완료 했을때 체크 표시가 나오지만, 할일이 있다는 점도 같이 나와서 사용자 입장에서 다 완료했는지 아니면 할일이 남았는지 명확하지 않을 수 있다.
AI B - Claude Sonnet 5.5 의 결과물은 달력에 선택한 날짜의 모든 할일 완료되었을때 점이 사라지고 체크표시만 보여진다. 그래서 사용자가 명확하게 확인 할 수 있다.

- AI B는 달력에 '오늘로 이동'이라는 버튼을 만들어 달력에서 날짜를 바꿔도 한번에 빠르게 오늘로 돌아올 수 있었다.
AI A는 달력에 오늘로 이동하는 버튼이 없어서 날짜를 바꿔도 다시 돌아가려면 일일히 수동으로 조작해서 오늘로 돌아와야했다.

- AI A는 할일을 완료하려고 클릭할때 정확이 네모박스만을 클릭해야지 완료가 되었다. 사용했을때 작은 네모박스를 무조건 클릭해야해서 불편했다.
AI B는 할일을 완료하려고 클릭할때 네모박스 부분이 아니어도 해당 할일의 전체 카드박스 부분을 클릭하면 완료가 되었다. 이 부분이 사용했을때 더 빠르게 완료 상태로 만들 수 있어서 좋았다.

## 수정 기록

### 수정 기록 1
- 발견한 문제: 사용자가 완료된 할일들이 더 이상 표시될 필요가 없다고 느껴서 완료된 할일들을 연속으로 많이 삭제했더니 (테스트 내용). 할일들이 문제 없이 모두 다 삭제된다 (예상 결과). 할일들이 모두 다 삭제 되었지만, 할일 하나를 삭제 할때마다 확인창이 뜨고 시간이 오래걸리고 불편했다.(실제 결과)
- AI에게 전달한 요청: 기획서에 '화면 구성과 동작' 부분에서 '선택한 날의 할일 목록' 부분에 "완료돤 할일들만 모두 한번에 삭제 할 수 있는 버튼이 있습니다. 버튼을 누르면 완료된 할일들만 모두 삭제됩니다." 줄을 추가했어. 그리고 '완료 기준' 부분에 "'완료 할일 모두 삭제' 버튼을 누르면 완료 할일들만 모두 삭제되고 미완료 할일들은 남아있습니다." 줄을 추가했어. 다른 기능과 화면은 그대로 유지한채 html에 이 수정 사항들만 고치고, 고친 HTML 파일을 완성된 .html 파일로 제공해 줘.
- 저장한 버전: `할일플래너_v1.html` → `할일플래너_v2.html`
- 수정 후 테스트 결과: 할일들을 10개 만들고, 9개 다 완료로 만들고 '완료 할일 모두 삭제' 버튼을 클릭했더니 완료 할일 9개가 모두 삭제되고 완료되지 않은 할일 1개는 그대로 남아있었습니다.
- 수정 이유: 많은 할일들이 있을때 이미 완료된 할일들을 개별적으로 삭제하는데 너무 많은 시간이 걸린다. 심지어 매번 확인창이 뜨기에 더더욱 많은 양의 완료 할일들을 삭제하기에 불편함.

### 수정 기록 2
- 발견한 문제: 사용자가 달력에 날짜를 선택할때 칸이 초록색으로 표시가 된다. (테스트 내용). 달력에서 날짜를 선택했을때 날짜 칸이 초록색으로 표시됨. (예상 결과). 칸이 초록새으로 표시가 되어서 할일을 다 완료한 것 처럼 보여질 수 있는 시각적 오해가 있다. (실제 결과).
- AI에게 전달한 요청: 기획서에 '화면 구성과 동작' 부분에서 '달력' 부분에 "달력에 날짜를 선택했을때 날짜 칸 색상이 연한 빨강으로 표시됩니다." 줄을 추가했어. 그리고 '완료 기준' 부분에 "선택 된 날짜의 모든 할일을 완료 했을때 달력에 날짜 색상이 초록색으로 표시됩니다." 줄을 추가했어. 다른 기능과 화면은 그대로 유지한채 html에 이 수정 사항들만 고치고, 고친 HTML 파일을 완성된 .html 파일로 제공해 줘.
- 저장한 버전: `할일플래너_v2.html` → `할일플래너_v3.html`
