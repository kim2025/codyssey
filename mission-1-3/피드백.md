# 피드백

## 잘된 점: 
### 직접 써 보니 좋았던 것
- 등급 색깔이 등급별로 달라서 구별이 쉬웠다.
- 등급 칸으로 영화 카드를 옮길때 등급 칸의 색상이 하이라이트 되어서 어떤 등급에 끌어다 놓는지 구별 하기 좋았다.
- 등급 알파벳 밑에 최고, 좋음, 보통, 아쉬움 같이 설명이 있어서 등급을 이해하기 쉬웠다.
- 맨위 우측에 "8편 중 2편 나눔" 같이 현재 진행도를 간단하게 알려주고 한눈에 볼 수 있어서 좋았다.
- 영화 카드를 클릭할때 검은색 테두리로 하이라이트 되어서 내가 어떤 영화 카드를 선택했는지 구별이 쉬워서 좋았다.
- 드래그 앤 드롭 방식으로 끌어다 놓을 수 도 있고, 영화 카드를 선택하고 등급을 클릭해도 배치를 할 수 있어서, 2가지 방식이 있어서 사용자 입장에서는 선택지가 있어서 좋았다.
- 영화 카드를 선택하고 '선택한 영화 되돌리기' 버튼을 눌러서 되돌리는 방식도 있어서 좋았다.
- 추가할 영화 제목을 입력하는 칸 아래에 사용자의 모든 액션이 기록으로 나와서 확인 할 수 있어서 좋았다.

### 기획서 완성 기준 피드백
- 영화 카드를 드래그 앤 드롭으로 옮기거나, 영화 카드를 선택해서 등급을 클릭해서 옮길떄 영화 카드가 한 칸에만 있고, 옮긴 칸에 남습니다.
- 영화 제목을 입력하고 추가를 누르면 아직 안 정한 영화에 생성 됨.
- '처음으로'를 누르면 처음 영화 8개가 등급 칸에서 모두 '아직 안 정한 영화'로 정상적으로 돌아갑니다
- html 파일을 열었을때 외부 파일이나 다른 로그인 없이 HTML 한 장으로 열립니다.

## 고치면 좋을 점
1. 본 것: [html 파일을 닫았다가 다시 열었더니]을 했더니 [데이터가 저장이 되지 않았다]가 나왔다

   기준: 기획서의 [같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다]을 충족하지 않음
   
   제안: [html 파일을 브라우저에서 닫았다가 새로 열어도 수정했던 데이터가 저장되어서 남아있으면 좋겠다]

2. 본 것: [화면 폭을 좁게 줄였더니]을 했더니 [오른쪽이 잘리게 표시가 되어 내용을 볼 수 없었다]가 나왔다

   기준: 기획서의 [화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다]을 충족하지 않음

   제안: [반응형으로 화면 폭이 좁아져도 내용이 잘리지 않고 볼 수 있으면 좋겠다]

3. 본 것: [제목 없이 영화를 추가 했더니]을 했더니 [빈 영화 카드가 생성 되었다]가 나왔다

   기준: 기획서에 없지만 쓰다가 불편했던 점

   제안: [영화 제목을 입력하지 않고 추가를 누르면 제목을 입력하라고 경고창을 띄우고 빈 카드가 생성이 되지 않게 하면 좋겠다]

4. 본 것: [개별로 영화를 삭제하고 싶었더니]을 했더니 [개별로 영화를 삭제 할 수 없었다]가 나왔다

   기준: 기획서에 없지만 쓰다가 불편했던 점

   제안: [영화를 잘못 추가 했을때 삭제 할 수 있게 영화 카드에 삭제 버튼이 있었으면 좋겠다]

5. 본 것: ['처음으로'를 '추가' 대신 실수로 눌렀더니]을 했더니 [모든 영화가 '아직 안 정한 영화'로 미분류 되었다]가 나왔다

   기준: 기획서에 없지만 쓰다가 불편했던 점

   제안: ['처음으로'를 실수로 눌렀을때 경고 메세지나 재확인 창이 떠서 사용자가 정말 초기화 하고 싶은지 물어보면 좋겠다]
