## AI가 물어서 내가 정한 것:
대화기록 캡쳐:

https://github.com/kim2025/codyssey/blob/mission-1-1/%E1%84%83%E1%85%A2%E1%84%92%E1%85%AA%E1%84%80%E1%85%B5%E1%84%85%E1%85%A9%E1%86%A8_%E1%84%8F%E1%85%A2%E1%86%B8%E1%84%8E%E1%85%A7.png

1. 사용자 범위: 본인(나)
2. 주요 동작: 영화를 드래그 앤 드롭 방식으로 분류
3. 등급 설정: S, A, B, C, D - 5등급으로 설정
4. 데이터 보관: 브라우저를 닫았다가 새로 열어도 데이터가 남아있게 설정
5. 영화 표시 방식: 텍스트 상자 형태
6. 목록 관리: 사용자가 영화를 추가/삭제 할 수 있게
7. 화면 레이아웃: 왼쪽에 등급 이름, 오른쪽에 빈칸있는 형식
8. 완성 기준: 영화를 드래그 앤 드롭 방식으로 분류 가능. 사용자가 영화를 추가/삭제 가능
9. 초기 데이터: 미션으로 제공된 8개의 영화를 미분류 그룹
10. 등급별 색상: 등급마다 다르게, 보편적으로 사용되는 색상
11. 미분류 영역 위치: 최하단
12. 삭제 방식: 'X' 버튼 클릭
13. 데이터 초기화: 초기화 버튼

## 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과):
1. 영화를 마우스로 클릭하여 미분류에서 드래그 앤 드롭 방식으로 티어 등급으로 이동 → 미분류에서 해당 등급칸으로 이동 → A 정상 이동 / B 정상 이동.

2. 영화 제목을 입력하고 추가 버튼을 누름 → 새로운 영화가 미분류 항목에 추가됨 → A 추가됨 / B 추가됨.

3. 영화에 'X' 버튼을 눌러서 삭제 → 해당 영화가 삭제됨 → A 삭제됨 / B 삭제됨.

4. 브라우저를 닫았다가 새로 열음 → 데이터가 저장되어 남아있음 → A 저장됨 / B 저장됨.

5. '전체 초기화' 버튼를 누름 → 모든 영화들이 미분류로 이동 → A 모든 영화가 미분류로 이동 / B 팝업으로 재확인 메세지로 물어본뒤, '확인' 버튼 누를시 모든 영화가 미분류로 이동.


## 선택한 파일명과 고른 이유:
AI A (Gemini 3 Flash)가 만든 결과 영화_A_초안.html 선택

A, B 둘다 PC에서 기획서대로 모든 기능은 정상 작동. PC에서 볼때 A 가 중심에 모든 부분이 있어서 보기도 사용하기도 더 편함. B 는 상대적으로 더 널게 퍼저있어서 시선이 조금 분산되고 마우스가 이동해야 하는 거리도 조금 더 김.

A, B 모바일에서도 둘다 모든 기능 정상 작동. 모바일 반응형 테스트시 A, B 둘다 정상 작동하나, A 는 등급표 레이아웃을 유지함. B 는 등급표 레아아웃을 유지하지 못함. 불편하게 UI가 바뀜.

A 의 '추가', '전체 초기화' 버튼이 섹깔을 사용해서 눈에도 잘 보이고 버튼을 누름으로 어떤 결과 나올지 시각적으로 도움이 됨. B 는 따로 버튼 색상을 사용하지 않고 무채색으로 표현.
