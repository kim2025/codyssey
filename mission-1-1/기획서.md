[내 영화 티어리스트 기획서]

1. 누가 쓰나
- 영화를 좋아하는 나 자신 (1인 전용)

2. 무엇을 하려고
- 본 영화들을 S, A, B, C, D 5단계 등급으로 분류하여 나만의 취향을 정리합니다.

3. 화면과 동작
- 레이아웃: 상단에 S, A, B, C, D 등급 행이 순서대로 있고, 최하단에 미분류 영화 목록이 위치함.
- 등급 표시: 각 행의 왼쪽에는 등급 이름이 있고, 오른쪽은 영화를 놓을 수 있는 빈 영역임.
- 이동: 영화 텍스트 상자를 드래그 앤 드롭하여 각 등급 칸이나 미분류 영역으로 자유롭게 이동 가능.
- 추가: 제목 입력 후 '추가' 버튼 클릭 시 최하단 미분류 영역에 새로운 영화 상자 생성.
- 입력 제한: 제목을 입력하지 않고 '추가' 클릭 시 "영화 제목을 입력해주세요!" 경고창(alert) 표시.
- 삭제: 각 영화 상자의 'X' 버튼을 눌러 해당 영화 삭제.
- 초기화: '전체 초기화' 버튼 클릭 시 모든 영화를 미분류 상태로 되돌림.
- 저장: 영화 목록과 배치 상태를 브라우저(LocalStorage)에 자동 저장하여 재접속 시 유지.
- 반응형: 스마트폰 등 모바일 기기에서도 레이아웃이 깨지지 않도록 구현.

4. 필요한 자료
- 초기 영화 목록: 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리
- 등급별 색상: 
  * S: 빨강 (#FF7F7F)
  * A: 주황 (#FFBF7F)
  * B: 노랑 (#FFFF7F)
  * C: 초록 (#7FFF7F)
  * D: 파랑 (#7FBFFF)

5. 완성 기준
- 드래그 앤 드롭으로 영화 카드를 자유롭게 배치할 수 있는가?
- 새로운 영화 추가 및 'X' 버튼으로 개별 삭제가 가능한가?
- 제목 미입력 시 경고창이 정상적으로 뜨는가?
- 새로고침 후에도 영화 위치와 목록이 유지되는가?
- '전체 초기화' 시 모든 영화가 미분류 영역으로 이동하는가?
- 모바일 화면에서도 콘텐츠가 적절하게 보이는가?
- 각 등급별 배경색이 기획대로 적용되었는가?
